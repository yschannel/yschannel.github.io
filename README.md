# yschannel · 世界线仪器交互样机

纯 HTML / CSS / JavaScript，可用于 GitHub Pages。当前是复古书桌风格首页、文章页，以及五篇明确标记的示例文章。探测仪仅保留小型本体，位于左侧文章架上方；首页下方为可横向滚动的文章标题卡片，点击进入正文。电脑与手机分别适配。已加入可视化写作后台、图片粘贴、私有草稿保存和本机发布；Cloudflare 登录、云端草稿和跨设备同步已接通并经用户验证，评论尚未接入。

## 书桌挂件

- 日历：使用访客浏览器当地日期，支持翻月与回到今天。按当前索引显示发布日期标记；点击日期定位当天或最近日期的文章，相同距离选较早日期。示例文章的日期均明确标注；实际发布的文章使用作者设置的日期。
- 索引卡：支持查找、内部滚动和自动文章计数。`archive.mjs` 中的 `seriesDefinitions` 配置名称、简介和入口文案；文章中新出现的标签也会自动成为索引。空索引有明确空状态，数量增加不需要改页面布局。当前分类不是最终分类设计。
- 系列便笺：跟随索引卡显示当前分类的标题、简介和入口；“全部”显示总览。入口滚动至对应文章架。
- 动漫示例包含可展开的剧透提示样式，无真实剧情。
- 文章架支持触摸、触控板、键盘和左右按钮浏览；滚动限于卡片容器。首页无需点击即可用左右方向键选文，Enter 打开。搜索输入框和控件保留自身键盘行为，正文页不拦截快捷键。
- 单篇或少量文章自动铺开，文章架下方显示当前卷宗及日期和键盘提示。
- 文章检索位于文章架上方，支持标题、正文、标签与结构化长文内容。支持空格分隔的多关键词同时匹配、大小写及全半角归一；页面加载时缓存检索文本，无外部服务。搜索与分类、日历、键盘选文共用结果集；提供匹配数量、清空、空状态及扩大到全部索引的入口。进出文章保留当前搜索，搜索框方向键操作光标，Esc 清空，Enter 提交后可用方向键/Enter 选文。
- 键盘浏览默认开启，有明确开关；点击索引或左右按钮之后，方向键仍能选文。输入框内保留光标操作。
- 独立文章阅读布局：隐藏首页挂件，扩大正文区域；顶部固定返回按钮、阅读进度、回到顶部，底部也有返回入口，Esc 返回。保留返回前的分类、选中文章与首页滚动位置。
- 同一台探测仪在首页与文章页之间移动：阅读时缩小放在固定工具栏里，退出时回到首页原位。复用同一组辉光管与动画状态，不重复创建或重置读数；手机工具栏优先保留返回、仪器及进度。
- 《搭一个属于自己的博客》为约 2200 字的原创排版示例，含七章、两张本地 SVG 原创配图、引用、列表、代码和折叠提示。图片可点击放大；目录宽屏侧置、窄屏折叠并固定在工具栏下方。

## 已确定的产品方向

- 个人文章、思考、项目过程与动漫记录；具体分类待定，预留项目系列与剧透提示。
- 作者使用可视化编辑器，支持选中文字设置格式、粘贴图片、草稿、预览与发布。
- 评论需要读者登录，目标支持图片与表情包。
- 优先免费方案，任何付费项必须先告知用户；音乐暂停开发。
- 视觉参考复古实验室、旧纸档案、暗绿金属与橙色辉光；不使用《命运石之门 0》第 12 集之后的剧情信息。

## 预览

运行 `npm ci`、`npm run build:admin`、`npm run dev`，然后打开 http://127.0.0.1:4175/ 查看博客，或 http://127.0.0.1:4175/admin/ 进入写作台。本机保存和发布仅影响这台电脑。完整上线步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。ES modules 需要 HTTP 服务，不要直接双击 HTML。

## 规则

- 首页相对基准：`0.000000`；文章值写在 `readings.mjs` 中，固定且互不相同。
- 数字对应关系为博客原创，不是动画中的计算公式。无《命运石之门 0》剧情内容。
- 视觉参考玻璃辉光管、电路底座、橙色发光；切换为风格化近似，未使用动画截图、音频或逐帧参考。
- 1900ms 切换：先暗下 180ms，数字跳变，逐位稳定。快速切换会取消上一段动画。
- 探测仪无外围标题、面板、说明或控制按钮；无声音，动画遵循系统减少动态效果偏好。
- 使用 hash 路由，文章可直接链接；返回、前进和刷新都能解析同一文章。
- 公开博客没有浏览历史追踪。写作后台通过 Cloudflare Worker 与私有 KV 保存登录会话和草稿；本机预览使用独立的本地存储。字体优先从 Google Fonts 加载，失败时使用系统字体。

## 发布

网站文件放在仓库根目录。GitHub 仓库 Settings → Pages → Deploy from a branch → main / (root)。网站已于 2026-10-30 发布到 https://yschannel.github.io/ ，写作后台为 https://yschannel-writing-desk.yschannel-blog.workers.dev/ 。GitHub Pages 来源是 main 分支根目录；初始部署提交为 9ea7968。用户已验证登录及跨设备草稿同步；首篇文章实际发布仍待验收。

## 验证

`npm test`；`npm run build:admin`；`node --check app.js`。覆盖文章索引与日期选择、富文本与图片发布、危险内容过滤、同名链接冲突、登录访问控制、跨站请求保护和草稿版本冲突。本机浏览器已检查格式编辑、图片粘贴、草稿恢复、预览及发布后阅读。线上登录与跨设备同步须部署后验证。


## 管理文章

进入在线写作台，使用 yschannel 登录。左侧「文件管理」和独立「回收站」提供取消发布（撤回）、删除文章、恢复与重新发布；「删除当前草稿」只回收草稿，不影响已公开文章。取消发布和删除适用于所有文章，包括示例文章。修改均有作者身份校验和确认弹窗，删除内容保存在私有回收站。公开仓库历史和配图文件不会随网站移除而清理。

文件管理分绿色已发布区与琥珀色草稿 / 未发布区，支持多选、全选和批量操作。回收站支持批量恢复、永久删除及清空，输入“永久删除”后才可提交。永久删除不可从后台恢复，不清理 GitHub 历史及已发布图片；独立草稿需单独处理。
